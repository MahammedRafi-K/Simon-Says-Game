Simon Says – Colors Game

A simple and interactive Simon Says Color Game built using HTML, CSS, and JavaScript.

The game tests your memory and reaction skills by generating a sequence of colored buttons that the player must remember and repeat correctly.

🕹️ How to Play
Press any key to start the game.
The game will flash one of the colored buttons.
Remember the color that was flashed.
Click the colors in the same order as shown by the game.
With every successful round, the sequence becomes longer.
If you click the wrong color, the game ends.
Try to achieve the highest score possible!
🎯 Game Features
🎨 Four different colored buttons
🧠 Memory-based gameplay
📈 Increasing difficulty
🔄 Random color sequence generation
⚡ Interactive button animations
🏆 Score/level tracking
❌ Game-over detection
📱 Simple and responsive design
🛠️ Technologies Used
HTML5 – Structure of the game
CSS3 – Styling, colors, animations, and layout

🧩 Game Logic

The game maintains two sequences:

Game Sequence – The sequence generated by the game.
User Sequence – The sequence entered by the player.

For every new level:
